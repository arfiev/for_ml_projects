# AI Agents Homework: Tool Calling, Memory Agent и Multi-Agent System

Учебный проект по реализации AI-агентов для небольшого интернет-магазина. В проекте последовательно реализованы три подхода к построению LLM-агентов: базовый ReAct-агент с инструментами, агент с краткосрочной и долгосрочной памятью, а также multi-agent система с разделением ролей между несколькими специализированными агентами.

Проект выполнен в формате Jupyter Notebook и использует LangChain для работы с LLM, tool calling и сообщениями диалога.

---

## Что реализовано

### 1. Tool-Calling Agent

Базовый агент, который умеет:

- понимать пользовательский запрос;
- вызывать инструмент поиска товаров;
- фильтровать товары по категории, бренду и цене;
- сортировать результаты по цене или рейтингу;
- добавлять выбранный товар в корзину;
- вести trace вызовов инструментов.

Основные инструменты:

- `search_products` — поиск товаров по каталогу;
- `add_to_cart` — добавление товара в корзину.

Агент работает в ReAct-цикле:

```text
User message → LLM → tool call → tool result → LLM → final answer

```

---

### 2. Memory Agent

Расширение базового агента памятью двух типов.

#### Long-term memory

Профиль пользователя сохраняется в JSON-файл:

```json
{
  "name": "Анна",
  "brand": "Sony",
  "max_price": "200"
}

```

Для работы с профилем реализованы функции:

- `load_profile` — загрузка профиля из JSON;
- `save_profile` — сохранение профиля в JSON;
- `update_profile` — инструмент для обновления предпочтений пользователя.

#### Short-term memory

История диалога хранится между ходами и включает:

- сообщения пользователя;
- ответы модели;
- результаты вызова инструментов.

Это позволяет агенту обрабатывать follow-up запросы, например:

```text
Пользователь: Найди беспроводные наушники до 150 долларов
Пользователь: Добавь первый из найденных в корзину

```

---

### 3. Multi-Agent System

Система из нескольких агентов, которые работают через общий `AgentContext`.

Архитектура:

```text
CoordinatorAgent
    ↓
RetrieverAgent
    ↓
ProsAgent
    ↓
ConsAgent
    ↓
RankerAgent
    ↓
Cart action, если пользователь просит добавить товар

```

Роли агентов:


| Агент              | Назначение                                                |
| ------------------ | --------------------------------------------------------- |
| `RetrieverAgent`   | Ищет релевантные товары через `search_products`           |
| `ProsAgent`        | Формирует плюсы каждого найденного товара                 |
| `ConsAgent`        | Формирует минусы каждого найденного товара                |
| `RankerAgent`      | Детерминированно выбирает лучший товар по рейтингу и цене |
| `CoordinatorAgent` | Оркестрирует весь пайплайн и формирует итоговый ответ     |


Ранжирование выполняется без LLM: сначала выбирается товар с максимальным рейтингом, а при равном рейтинге — более дешёвый вариант. Если задан бюджет, товары дороже бюджета отфильтровываются.

## Как запустить

### 1. Установить зависимости

В ноутбуке используется:

```python
%pip install -q langchain-openai langchain-core

```

Также можно установить зависимости через терминал:

```bash
pip install langchain-openai langchain-core

```

### 2. Указать переменные окружения

Для запуска через Yandex Cloud / AI Studio нужны:

```python
OPENAI_API_KEY = "your_api_key"
YANDEX_FOLDER_ID = "your_folder_id"

```

Модель задаётся в формате Yandex Cloud model URI:

```python
MODEL_NAME = f"gpt://{YANDEX_FOLDER_ID}/gpt-oss-20b/latest"

```

Подключение к OpenAI-compatible endpoint:

```python
llm = ChatOpenAI(
    model=MODEL_NAME,
    temperature=0,
    api_key=OPENAI_API_KEY,
    base_url="https://ai.api.cloud.yandex.net/v1",
)

```

### 3. Запустить ноутбук

Порядок запуска:

1. Запустить ячейку с шаблоном.
2. Запустить ячейки с реализацией заданий.
3. Запустить открытые проверки для заданий 1, 2 и 3.

## Примеры сценариев

### Поиск товара

```text
Найди беспроводные наушники до 150 долларов

```

Ожидаемое поведение:

- агент вызывает `search_products`;
- применяет фильтр по цене;
- возвращает подходящие товары из каталога.

---

### Поиск и добавление в корзину

```text
Найди беспроводную мышь дешевле 120 долларов и добавь самую дешёвую в корзину

```

Ожидаемое поведение:

- агент ищет беспроводные мыши дешевле 120 долларов;
- сортирует результаты по цене;
- добавляет самый дешёвый товар в корзину.

---

### Использование памяти

```text
Меня зовут Анна, я предпочитаю Sony и трачу не более 200 долларов

```

Агент сохраняет предпочтения пользователя в профиль.

Затем в новой сессии можно спросить:

```text
Как меня зовут и какой мой бюджет?

```

Агент использует сохранённый профиль и отвечает на основе долгосрочной памяти.

---

### Multi-agent подбор товара

```text
Найди лучшую беспроводную мышь до 120 долларов и добавь в корзину

```

Пайплайн:

1. `RetrieverAgent` ищет кандидатов.
2. `ProsAgent` описывает плюсы.
3. `ConsAgent` описывает минусы.
4. `RankerAgent` выбирает лучший вариант.
5. `CoordinatorAgent` добавляет товар в корзину и формирует итоговый ответ.

---

## Проверки

В ноутбуке есть открытые проверки для каждого блока.

Проверяется, что:

- `search_products` вызывается при поиске;
- фильтр по цене работает корректно;
- `add_to_cart` добавляет нужный товар;
- `update_profile` сохраняет предпочтения пользователя;
- агент использует профиль из JSON;
- short-term memory сохраняет результаты предыдущего поиска;
- multi-agent pipeline вызывает нужные делегаты;
- `RankerAgent` учитывает рейтинг, цену и бюджет.

## Основные идеи проекта

Проект демонстрирует несколько важных паттернов разработки LLM-приложений:

- описание Python-функций как LLM-инструментов;
- ручная реализация ReAct-цикла;
- работа с `AIMessage`, `ToolMessage` и `tool_call_id`;
- хранение состояния между вызовами агента;
- сохранение пользовательских предпочтений в JSON;
- разделение сложной задачи между несколькими агентами;
- детерминированное ранжирование вместо передачи всей логики выбора LLM.
